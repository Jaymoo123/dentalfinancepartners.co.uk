# Link engine judgment rubrics

`cluster_owner.md` is the rubric for the judgment agent that resolves cluster conflicts and picks an owner page for families the WP1 assignment does not cover. Verdicts are cached in `docs/<site>/link_engine/<run>/judgments/*.jsonl`, keyed by the `input_sha256` of the queue row (or conflict row) the reader saw, so a changed row is re-judged and an unchanged one never is; `apply_judgments.py` refuses any verdict whose hash no longer matches. Low-confidence verdicts get a second independent reader (a separate agent that does not see the first verdict); only disagreements between readers go to the owner, as `OWNER DECISION NEEDED`. Owner rulings are recorded in `scripts/link_engine/sites/<site>_rulings.md`, which the rubric tells every reader to read first, so a ruling made once is never asked twice.
