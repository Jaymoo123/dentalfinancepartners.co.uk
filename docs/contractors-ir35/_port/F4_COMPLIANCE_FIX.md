## Undisclosed processor found (reported, not acted on)

**ZeroBounce.** `src/lib/leads/verify.ts:97-116` calls `https://api.zerobounce.net/v2/validate` with the enquirer's email address, from the live submit path (`src/app/api/leads/submit/route.ts:17,87`). It is gated on `process.env.EMAIL_VERIFY_API_KEY` being set; with no key it falls back to an in-house DNS MX check. Whether the key is set on the live Vercel project cannot be read from the repo, so this is not asserted either way and no disclosure was added. If the key IS set, the privacy policy's processor list is missing a named processor that receives personal data, which is a false disclosure by omission.

**Twilio scope is narrower in the copy than in the code.** The bullet says Twilio is used "sending the text messages we use to confirm your details". The code also uses Twilio Lookup v2 for phone validation (`verify.ts:54`) and a WhatsApp send path (`channels.ts:167-173`, gated on `LEAD_NURTURE_WHATSAPP_ENABLED` + `TWILIO_WHATSAPP_FROM`). Same processor, so no undisclosed third party, but the stated purpose is incomplete. Left alone: the WhatsApp branch is env-gated and unreadable from the repo.

**Admin session cookie.** `src/app/api/admin/login/route.ts:78` sets a session cookie on the operator-only `/admin` area. The cookie policy's "we do not currently use any strictly necessary cookies" is about visitors and stays as written; flagged so it is a known, decided position rather than an unnoticed one.
