## 13. FALSE OR IMPRECISE PREMISES IN THE BRIEF

1. **"`/cis-*-template` pages drew 27 sessions and 28 template-download clicks, with ZERO capture."** Half true, and the half that is false changes the work. `/cis-payment-deduction-statement-template` has **no capture form at all**. `/cis-invoice-template` **does**: a full `LeadForm submitLabel="Request a callback"` at `:257`, inside a white card in the closing navy band. The family is uninstrumented and under-asking, which is the real finding, but "zero capture" as stated would have had a builder add a second form to a page that already has one. Zero *recorded* capture events is separately true and consistent: `LeadForm` emits `form_field_focus`/`form_start`, not `form_step_view`, and neither fired on either page.
2. **"Its matching `deep_scroll_modal` open event has never once fired, so there is no denominator and the modal's value is unmeasurable as instrumented."** The denominator exists. `deep_scroll_modal` is a **click** id on the offer link (`DeepScrollModal.tsx:114`); the modal's open fires `personalization_shown` with `surface='deep_scroll_modal'` (`:220` -> `IntentProvider.tsx:88-92`). Phase 0 queried only `cta_click`, so it could not see it. Query before instrumenting (§9). Nothing needs building here.
3. **"The 4 research pages ... are recharts WITH data tables beside every chart."** The a11y conclusion stands and nothing should be "fixed": no `role="img"`, no `aria-hidden`, `grep` across `src/components/research/` is empty, so the Generalist collapse defect genuinely does not exist. But **"beside every chart" is not accurate**: each page ships 1-2 tables and the pairing is inconsistent: the index page's annual chart, insolvency's annual and monthly charts, and survival's `SurvivalCurveChart` and `OneYearTrendChart` have no adjacent table, while PPR's fastest-10 table and insolvency's procedure table stand with no chart. Phase 0's own per-page counts (2/2/2/1) already said this; the brief's summary of them over-claims. Recommendation: leave it (recharts renders its own labels and no subtree is hidden), and treat completing the pairing as an optional content gate, not a port task.
4. **`DetailsForm.tsx:192`** is correct as cited. Recorded because two other line citations in the brief's family were worth re-deriving and this one held.
5. **Two live defects this slice found that are in no Phase 0 artefact**, proposed as TD-31 and TD-32: (a) all 5 research routes render the `Breadcrumb`'s **light-ground default variant inside a `bg-neutral-900` hero**, with the component's own `variant="light"` never passed (§3.5); (b) `StickyCTA.tsx:147` ships **`data-cta-id`**, which `autoCapture.ts:100` does not match, so the site's only persistent site-wide CTA has never emitted a single `cta_click` and its dismiss button has no id at all (§6).
