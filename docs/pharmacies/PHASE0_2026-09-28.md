### Changed

- `app/globals.css` - the closures post measured 562 at 390. Cause: the post body embeds raw
  `<table>` markup with no wrapper and `packages/site-styles/prose-standard.css` sets
  `.prose table { width: 100% }` with no max-width guard, so a five-column table widened the page
  (the offending `<table>` measured `right: 562`). Fixed with a scoped
  `.prose table:not(.not-prose *) { display:block; overflow-x:auto; max-width:100% }`, the same fix
  hospitality carries, kept out of the shared package because that is not this site's boundary.
- `app/about/page.tsx`, `app/services/page.tsx` - both rendered zero forms. Each now closes on the
  same navy lead band the slug templates use, with this site's `LeadForm`, an authored heading and
  line, and "Free first call, then a fixed fee in writing". No new pattern was introduced.
- `app/calculators/[slug]/page.tsx` - removed the `calc_page_footer` `MiniCapture`; the route had two
