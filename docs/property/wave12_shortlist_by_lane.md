**How to read it:**
- KD was not returned in the dry-run (shown as n/a). Winnability (Win) is SERP-verified for the top 40 candidates by score; all others carry the neutral 0.75 placeholder. Verified 1.0 values are called out.
- Action = NEW PAGE / UPGRADE `<slug>` / NEW CALCULATOR / HUB SECTION. Upgrades target keywords where we already hold the asset and the demand data says the head term is bigger than the page currently targets.
- Volume figures are the primary keyword only; most picks carry variant clusters on top.
- Excluded throughout: Wave 11 topics (EICR, licensing overview, EPC cost/booking, MEES, lease extension, RTM, service charge, ground rent, LAFRA, commercial EPC), all §10 out-of-scope topics, navigational HMRC queries (login, contact number, address), and off-topic mislanes (child/working tax credit, ISA accounts).
