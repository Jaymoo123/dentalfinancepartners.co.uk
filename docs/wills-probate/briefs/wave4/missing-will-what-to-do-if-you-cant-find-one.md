## SERP Evidence
Query run: "missing will what to do"

- Taylor Bracewell, elm-online, The Gazette, National Will Register and Thornton Jones all cover the same core path: search the home and ask relatives/solicitors first; then use a professional will-search service (National Will Register holds 5m+ registered wills); a copy will can sometimes be used if the original is genuinely lost.
- Key legal risk flagged consistently: if a will was last known to be in the deceased's possession and can't be found, there's a legal presumption it was destroyed to revoke it — this presumption must be rebutted before a copy can be used.

## Gap / Angle
- The 'presumed destroyed = presumed revoked' rule is the single highest-value fact in this topic and is usually buried mid-article — we should foreground it since it's the fact that determines whether a copy will can even be used, directly affecting whether intestacy rules apply instead.
