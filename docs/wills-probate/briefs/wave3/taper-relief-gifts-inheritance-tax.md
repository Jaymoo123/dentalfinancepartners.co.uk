Matches the brief's assumed figures exactly — no discrepancy found. One important nuance repeatedly flagged: taper relief only has any effect where cumulative gifts in the 7 years before death exceed the £325,000 nil-rate band; below that threshold there is no tax to taper in the first place, a point several results treat as an FAQ but this brief should state up front to avoid the most common reader misconception.
